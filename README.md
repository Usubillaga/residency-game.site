# residency-game.site

Impressum, Datenschutz und Hilfe der App „Residency Game: Urologie“ (Google Play, App Store), veröffentlicht über GitHub Pages:

- Start: https://usubillaga.github.io/residency-game.site/
- Datenschutz: https://usubillaga.github.io/residency-game.site/privacy.html
- Hilfe und Impressum: https://usubillaga.github.io/residency-game.site/support.html

Die Seiten sind Kopien aus dem privaten Spiel-Repository (`privacy.html`, `support.html`, `assets/page-lang.js`, `assets/favicon.svg`). Änderungen dort zuerst machen und hierher übernehmen, damit App und Website gleich bleiben.

Einrichtung: Settings → Pages → Source „Deploy from a branch“ → Branch `main`, Ordner `/ (root)`.
